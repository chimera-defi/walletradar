# Wallet Setup Guide: Hardware and Software

## Hardware Wallet Setup

### Quick Checklist

1. Buy from the official vendor only.  
2. Update firmware on first boot.  
3. Generate a new seed on-device (never import old seeds).  
4. Write the seed offline; never photograph it.  
5. Enable a passphrase if supported.  

### Step-by-Step Setup

#### Step 1: Verify Device Integrity
- Check tamper seals (if provided).
- Confirm serial and authenticity via vendor tools.

#### Step 2: Initialize On-Device
- Generate a new seed on the device.
- Record the seed offline (paper or metal backup).

#### Step 3: Configure Security
- Set a PIN.
- Enable passphrase (recommended).

#### Step 4: Test Recovery
- Perform a recovery test using the recorded seed.

#### Step 5: Transfer Funds
- Send a small test transaction before large transfers.

## Software Wallet Setup

### Quick Checklist

1. Download from the official site or app store.  
2. Create a new wallet and secure the seed.  
3. Enable biometrics/lock screen.  
4. Verify network settings before connecting dApps.  
5. Start with small test transactions.  

### Step-by-Step Setup

#### Step 1: Install from Official Source
- Use vendor website or verified app store listing.

#### Step 2: Create a New Wallet
- Generate a new seed.
- Store it offline (no screenshots or cloud notes).

#### Step 3: Lock Down Access
- Enable biometric lock or strong PIN.
- Turn on phishing/scam warnings if available.

#### Step 4: Connect to dApps
- Verify the dApp URL.
- Check approvals before signing.

#### Step 5: Test First
- Send a small test transaction.
- Confirm you can recover using the seed.

## FAQ

**Should I import an old seed into a hardware wallet?**  
No. Always generate a fresh seed on the device.

**Do I need a passphrase?**  
Recommended for stronger protection.

**Is a software wallet safe?**  
It is safe for daily use if you follow good security practices.

**Should I use multiple wallets?**  
Yes, separate daily funds from long-term storage.

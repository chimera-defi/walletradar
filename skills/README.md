# WalletRadar Skills Bundle

This repository includes a local copy of the most-used workflow skills so agent behavior remains reproducible after extraction from the monorepo.

## Included Skills

- `token-reduce` — low-token discovery + scoped retrieval workflow.
- `taste-skill` — premium frontend design baseline.
- `redesign-skill` — upgrades existing UI quality while preserving functionality.
- `soft-skill` — high-end visual design constraints.
- `minimalist-skill` — editorial/minimal visual style.
- `brutalist-skill` — industrial brutalist UI style.
- `gpt-tasteskill` — advanced motion-heavy premium design workflow.

## Notes

- These are copied skill docs (`SKILL.md`) for repo-local portability.
- If upstream skills change, update this folder intentionally and note the update in PR summary.
- Keep WalletRadar-specific operating rules in `AGENTS.md` and `.cursorrules`; use this folder as reusable skill references.

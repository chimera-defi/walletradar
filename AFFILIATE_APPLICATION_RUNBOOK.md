# Affiliate Application Runbook (First Pass)

This runbook is for the first full application sweep across tracked affiliate programs.
Use it with `AFFILIATE_TARGETS.md` and issue #33/#34/#35.

## Goal

- Submit first-wave applications in one focused session
- Keep copy/paste answers consistent
- Record outcomes immediately to avoid rework

## Session Plan (90 Minutes)

1. Fill the "Application Packet" below once.
2. Submit all `P0` programs in sequence.
3. Log each submission result in `AFFILIATE_TARGETS.md` notes.
4. Open follow-up tasks for missing tax/payment setup.

- **Day 0:** submit all wave-1 applications.
- **Day 3:** send follow-up where no confirmation email arrived.

- **Day 14:** close loop (approved/rejected) and update tracker priorities.

## Guardrails

1. Do not publish tracking links before explicit approval.
2. Always add disclosure text near affiliate CTAs.
3. Keep ranking/scoring logic independent from monetization outcomes.
4. Log all launches and major status changes in `CHANGELOG.md`.
